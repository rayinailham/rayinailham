## Projects

**[FutureGuide](https://github.com/WIS-futureguide)**: career guidance platform. Go services (atlas, apollo, argus, athena), RAG on Gemini, QRIS payments, all on Docker.

**[Kairos](https://github.com/rayinailham)** (WIP): desktop app that finds clip-worthy moments in long VODs, using the transcript and chat activity. Python, PyQt6, yt-dlp, FFmpeg.
